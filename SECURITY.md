# Security Policy

## Supported Versions

Only the latest major version of this package is actively supported with security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please email hammadarain05@gmail.com instead of opening a public GitHub issue.

Please include as much detail as possible (steps to reproduce, affected version, potential impact) to help triage the report quickly.

You can expect an initial response within a few days. Once a fix is confirmed, a new release will be published and the issue will be disclosed responsibly.
